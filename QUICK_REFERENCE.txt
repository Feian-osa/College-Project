================================================================================
                          DATA ITEM STRUCTURE
================================================================================

Each inventory item contains:

Field Name        | Type    | Example           | Purpose
─────────────────────────────────────────────────────────────────
itemID            | string  | ITM001            | Unique identifier
itemName          | string  | Steel Pipe        | Product name
category          | string  | Hardware          | Classification
quantity          | int     | 100               | Current stock level
reorderLevel      | int     | 20                | Alert threshold
unitPrice         | double  | 15.50             | Price per unit
entryDate         | string  | 2025-12-04        | Date added to system

Example Item Record:
  ITM001|Steel Pipe|Hardware|100|2025-12-04|20|15.50

================================================================================
                       MODULE RESPONSIBILITIES
================================================================================

INVENTORY MODULE (Inventory.h/cpp)
├─ Purpose: Core data management
├─ Handles: CRUD operations, file persistence
├─ Classes: InventoryItem, InventoryManager
└─ Key Methods: addNewItem(), viewAllItems(), searchItem(), 
                updateItem(), performStockInOut(), deleteItem()

REPORT WRITER MODULE (ReportWriter.h/cpp)
├─ Purpose: Business analysis and reporting
├─ Handles: 4 types of reports + summary
├─ Class: ReportWriter
└─ Reports: Inventory, LowStock, Value, Category-wise

LOW STOCK ALERT MODULE (LowStockAlert.h/cpp)
├─ Purpose: Inventory monitoring and alerts
├─ Handles: Threshold checking, urgency levels
├─ Class: LowStockAlert
└─ Features: Custom thresholds, alert dashboard

TRANSACTION LOGGER MODULE (TransactionLogger.h/cpp)
├─ Purpose: Audit trail and operation tracking
├─ Handles: All operations logged with timestamps
├─ Classes: Transaction, TransactionLogger
└─ Types: ADD, UPDATE, DELETE, IN (Stock), OUT (Stock)
