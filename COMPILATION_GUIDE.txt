============================================================================
                        TROUBLESHOOTING
============================================================================

ERROR: "g++ is not recognized as an internal or external command"
------
Solution: 
1. Install GCC (MinGW/MSYS2)
2. Add GCC to Windows PATH
3. Verify: Open cmd and type "g++ --version"

---

ERROR: "No such file or directory: Inventory.cpp"
------
Solution:
1. Ensure you're in the correct directory
2. Verify file names (case-sensitive on some systems)
3. Use full path: g++ -std=c++11 -o inventory.exe "C:\...\main.cpp" ...

---

ERROR: Compilation errors with "-std=c++11"
------
Solution:
1. Try newer standard: -std=c++14 or -std=c++17
2. Verify GCC version: g++ --version
3. Update GCC if outdated

---

ERROR: "inventory.exe not found" after compilation
------
Solution:
1. Check if compilation succeeded (no error messages)
2. Look for inventory.exe in current directory
3. Try with explicit path: .\inventory.exe

---

ERROR: "File inventory.txt already in use"
------
Solution:
1. Close any running instances of inventory.exe
2. Restart the program
3. If it persists, check Windows Task Manager

============================================================================
                    COMPILATION FLAGS EXPLAINED
============================================================================

-std=c++11      Use C++11 standard (recommended for compatibility)
-std=c++14      Use C++14 standard (newer features)
-std=c++17      Use C++17 standard (latest features)

-o filename     Output executable name
-c              Compile only (create .o object files)
-Wall           Show all warnings
-g              Include debug information

Example with flags:
g++ -std=c++11 -Wall -g -o inventory.exe main.cpp Inventory.cpp ReportWriter.cpp LowStockAlert.cpp TransactionLogger.cpp

============================================================================
                        DATA FILES CREATED
============================================================================

When you run the program, it creates:

1. inventory.txt
   - Stores all inventory items
   - Format: ID|Name|Category|Qty|Date|ReorderLevel|Price
   - Auto-created on first run

2. transactions.txt
   - Stores transaction history
   - Format: TxnID|Timestamp|Type|ItemID|Name|Qty|Description
   - Auto-created on first run

3. Reports/ (Directory)
   - Created when you generate reports
   - Contains timestamped report files
   - Created automatically if missing

============================================================================
                        VS CODE SETUP
============================================================================

If you want to build directly in VS Code:

1. Install C++ extension by Microsoft
2. Press Ctrl+Shift+D to open Run & Debug
3. Create launch.json with:

{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Build and Run",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceFolder}/inventory.exe",
            "args": [],
            "cwd": "${workspaceFolder}",
            "preLaunchTask": "build"
        }
    ],
    "tasks": [
        {
            "label": "build",
            "type": "shell",
            "command": "g++",
            "args": [
                "-std=c++11",
                "-o", "inventory.exe",
                "main.cpp",
                "Inventory.cpp",
                "ReportWriter.cpp",
                "LowStockAlert.cpp",
                "TransactionLogger.cpp"
            ]
        }
    ]
}

Then press F5 to compile and run!
