================================================================================
                        DATA FILES CREATED AT RUNTIME
================================================================================

When you run the program, it will create:

1. inventory.txt (created when you add first item)
   Format: ItemID|Name|Category|Qty|EntryDate|ReorderLevel|Price
   Example: ITM001|Steel Pipe|Hardware|100|2025-12-04|20|15.50

2. transactions.txt (created on first operation)
   Format: TxnID|Timestamp|Type|ItemID|Name|Qty|Description
   Example: TXN0001|2025-12-04 15:30:45|ADD|ITM001|Steel Pipe|100|New item added

3. Reports/ (directory auto-created on first report)
   Contains: Timestamped report files
   Example: Inventory_Report_2025-12-04.txt
