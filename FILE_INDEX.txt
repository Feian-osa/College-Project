================================================================================
                         GENERATED FILES
================================================================================

These files are created when you run the program:

📊 inventory.txt
   ├─ Auto-created on: First time you add an item
   ├─ Format: Pipe-delimited (ID|Name|Category|Qty|Date|ReorderLevel|Price)
   ├─ Example:
   │  ITM001|Steel Pipe|Hardware|100|2025-12-04|20|15.50
   │  ITM002|Valve|Hardware|50|2025-12-04|10|25.00
   └─ Purpose: Persistent inventory data storage

📊 transactions.txt
   ├─ Auto-created on: First operation
   ├─ Format: Pipe-delimited (TxnID|Timestamp|Type|ItemID|Name|Qty|Description)
   ├─ Example:
   │  TXN0001|2025-12-04 15:30:45|ADD|ITM001|Steel Pipe|100|New item added
   │  TXN0002|2025-12-04 15:31:22|IN|ITM001|Steel Pipe|50|Stock received
   └─ Purpose: Complete audit trail of all operations

📁 Reports/ (Directory)
   ├─ Auto-created on: First report generation
   ├─ Contains timestamped report files:
   │  ├─ Inventory_Report_YYYY-MM-DD.txt
   │  ├─ LowStock_Report_YYYY-MM-DD.txt
   │  ├─ InventoryValue_Report_YYYY-MM-DD.txt
   │  ├─ Category_Report_YYYY-MM-DD.txt
   │  └─ TransactionHistory_YYYY-MM-DD.txt
   └─ Purpose: Generated business reports
